This is a Python script that generates transparent HDR angular-grid EXR textures with latitude/longitude labels.

I use the generated coordinate-grid image as a reference while writing skybox shaders, allowing me to more intuitively see the positions of other elements drawn on the skybox.

Yes, the script was generated with AI. But since this task involved many small details that could not be produced correctly in a single-shot, I decided to publish it for others to reference.
